# 班長版（大電視）— 一頁看懂

**網址**：大電視開 `http://<主機>:8000/?lang=zh&tv=1`（不用登入）。畫面每 30 秒換一次，依序是：最新工單的「趨勢」→ 最新工單的「預測」→ 全部工單的「趨勢」→ 全部工單的「預測」，再回到最新工單。也就是最新工單與全部工單每 60 秒切換一次，各自都會顯示趨勢與預測。加了 `tv=1` 就一直輪播；一般電腦則是 5 分鐘沒人操作才開始輪播，輪播會把篩選改成最新工單或全部工單。

**畫面上是哪個產品**：標題旁的藍色標籤是目前畫面的產品（例如 `TN-250_EDM-G-8MP`），後面是工單號，最新工單會標「（最新）」。看全部工單時，標籤是灰色的「全部產品 · 全部工單」。

## 1. 先看最上面：提醒橫幅

只有最近 24 小時有狀況時才會出現，點一下會帶到相關頁面。

| 顏色 | 代表 | 常見內容 |
|---|---|---|
| 紅 | 異常 | 某張工單良率低於 95%，或連續 3 台 FAIL |
| 黃 | 注意 | 同一工單 60 分鐘內多台同樣的失敗（先查測試站）、吞吐量比平常低、重測率偏高、近 1 小時產出低於目標 |
| 藍 | 提醒 | 某張工單已經很久沒有測試、有 FAIL 還沒登記處置 |

## 2. 趨勢畫面（目前這張工單）

- **良率**大字：綠 ≥ 98%、黃 ≥ 95%、紅 < 95%（門檻可在設定頁改）。左邊是 PASS / FAIL 比例。
- 測試台數、PASS、FAIL、重測率、2.4G / 5G 平均吞吐量。
- 四張圖：良率趨勢、**每小時產出**（07:00–19:00，黃色虛線是每小時目標）、每月台數、吞吐量分布。

## 3. 預測畫面

- 有計畫數時：**預計完成時間**、剩餘台數、目前速度（台 / 時）、每個工作日大約能測幾台。
- 沒有計畫數時只看得到速度；請管理者在工單頁設定計畫數。
- 選「全部工單」時：本週、本月已測與預估，和上週 / 上月比較。

## 4. 有 FAIL 時

到「失敗清單」看每台的**建議動作**：「重測一次」「先查測試站」「交 RD / 送修」，或 RD 寫給產線的指示。重測通過的會自動結案。
