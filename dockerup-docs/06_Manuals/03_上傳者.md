# 上傳者版（上傳 Log）

登入：「上傳 Log」頁輸入管理者給你的帳號密碼。登入後首頁就是上傳頁。

## 三個步驟

1. **選擇 log**：把桌面工具的交付 zip 拖進框裡（或按「選擇資料夾」）。分析完會自動到下一步，上方只留一行摘要：幾份 log、幾台、PASS / FAIL、已在資料庫幾份（已存在的會略過，重複上傳是安全的）。
2. **確認**：填產品（從清單選；新產品選「新增產品」）、工單號（沒有就填 `NOWO`）、計畫測試數量。
   - 右邊「助理」會幫你對照：檔名推斷的產品 / 工單和你填的一不一樣（不一樣會給「用 X」按鈕）、這張工單有沒有計畫數、還有幾個錯誤或警告。
   - 工單已經有計畫數時，數量欄下面會出現「沿用 N」按鈕。
   - 有黃色警告時要勾「我已確認」才能上傳；紅色錯誤要先改。
   - 想用對話方式填，按「使用 AI 對話」。
3. **結果**：新增 / 略過 / 錯誤筆數，以及「**這批 vs 該產品歷史**」（良率、2.4G / 5G 中位數和平常比、主要失敗）。想要一段文字說明可按「AI 說明」。按「查看工單」看這張工單的詳情；「上傳下一批」重新開始。

## 上傳錯了

在結果頁或下面的「我的上傳紀錄」按「撤銷」：只刪掉這一批新增的資料，計畫數回到上傳前。

## 常見訊息

| 訊息 | 怎麼辦 |
|---|---|
| 工單號格式錯誤 | 4 碼、一槓、YYMMDD 加 3 碼流水號，例如 `5101-251216015`；沒有工單填 `NOWO` |
| 產品不在辨認庫、而且 TN 號碼已屬於另一個產品 | 多半是打錯字，按建議的產品名稱 |
| log 已在資料庫（別的工單 / 產品） | 確認是不是選錯工單；確定沒錯就勾確認 |
