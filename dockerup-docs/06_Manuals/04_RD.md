# RD 版（進階分析）

登入：RD 帳號（管理者在帳號管理建立，角色選 RD）。RD 可以看所有資料，但不能上傳、不能新增產品。登入後首頁就是「進階分析」。

## 找出一群 FAIL

上方篩選列（範圍、產品、工單）＋本頁的條件：現象、頻段、SSID 群組、Port、重測結果、分類來源（規則 / AI / RD）、RD 狀態、環節、吞吐量與 RSSI 區間、搜尋（SN、MAC、工單、備註）、只看仍失敗的機台。

| 分頁 | 用途 |
|---|---|
| 總覽 | 柏拉圖（依現象、產品、站別、工單、時段、星期…分組；綠色是其中重測後通過的）；交叉表（例如現象 × 站別、現象 × 時段）；**問 AI**：只把這群 FAIL 的統計交給 AI，請它說共同點、可能原因、下一步檢查 |
| FAIL 清單 | 每筆的量測值、站別、測試序列；勾選多筆一次改分類 / 環節 / 狀態 / 負責人 / 備註 / **給產線的指示**；匯出 CSV、匯出 log（zip） |
| 機台歷程與 log | 一台機台的每一次測試；選 A、B 兩次左右對照 log（證據行紅底、結果 / 錯誤行黃底）；「相似案例」找同樣錯誤行或同站前後 2 小時的 FAIL |
| 分類法 | 改名、改建議動作、新增、停用、合併（合併後舊分類的記錄全部移過去，新的 FAIL 也照新分類）；刪除只限自己加、沒人用的分類 |

## 你的決定會怎麼回到產線

- 改過的分類不會被規則改回去；想撤回可以「回到規則分類」。
- 「給產線的指示」會直接變成失敗清單的建議動作，也會接在該工單的狀態一句話後面（工單清單、工單詳情）。
- 每次變更都記在異動紀錄（FAIL 詳情視窗看得到）。
