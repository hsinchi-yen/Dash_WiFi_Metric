# 管理者版

登入：任一管理頁（例如「設定」）輸入 `qc` / `qcpass`（環境變數 TWEAK_USER / TWEAK_PASS）。登入後首頁是「趨勢」。

## 每天 / 每週會用到的

| 功能 | 在哪裡 | 說明 |
|---|---|---|
| 趨勢 / 預測 | 首頁上方切換 | 篩選列（範圍、產品、工單）兩邊共用；預測不受日期範圍影響，一律從現在起算 |
| 工單狀態 | 工單 | 狀態燈與一句話（紅 / 黃燈由 AI 口語化，其餘規則句）；勾兩張可比較 |
| 工單詳情 | 點工單號 | 事實、上一張同產品比較、失敗分類、結案報告與追問；**設定計畫數**（只有管理者） |
| 週報 / 月報 | 報表 | 上週、上個月會自動產生；也可以指定任一週 / 月「產生」。下載 Markdown（中 / 英）或列印成 PDF |
| 問看板 | 右上 💬 | 例如「上個月測了幾台」「今年各產品的良率」。只回答彙總數字，數字直接來自資料庫；畫面會寫出它怎麼理解你的問題 |

## 設定（設定頁）

- 良率門檻（綠 / 黃）、上班時間與**上班日**（預測只算這幾天）、多久算「進行中」、多久算「完成」、連續 FAIL 幾台要提醒、吞吐量下滑多少 % 要提醒、近一小時落後目標多少 % 要提醒。
- 每個產品的每小時目標（空白 = 用該產品歷史中位數）。
- **AI 使用量**：每天、每種用途呼叫了幾次 LLM（保留 90 天）。

## 帳號（帳號管理）

- 新增上傳者或 RD；停用、重設密碼；變更角色後該帳號會被登出。
- 異動紀錄、登入紀錄可篩選。

## 資料庫維護

- 選產品 / 工單瀏覽資料；**匯出 CSV**（不含原始 log）。
- 每列「⋯」：下載 log、刪除一筆；「刪除整張工單」需要輸入工單號。**刪除前一律先顯示影響**：會刪幾筆、幾台、連帶移除的失敗分類 / 處置 / RD 分析、工單刪除前後的台數與良率。
- 「上傳批次」分頁：撤銷某次網頁上傳（只刪該批新增的資料，並還原計畫數）。
